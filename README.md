# defy

defy is a quality-of-life mod for Hypixel SkyBlock, with a modern native menu, customizable appearance, profiles, and keyboard bindings.

## Current features

Development is active, features are slowly being added :)

The menu includes feature search, individual key bindings, profile creation/renaming, a selectable startup profile, four themes (Light, Silver, Ash, Dark), None/Blur/Glass backgrounds, and optional background dimming.

## Requirements and installation

- Minecraft **26.3** (support for older/newer versions coming soon)
- Java **25**
- Fabric Loader **0.20.1 or newer**
- Fabric API for Minecraft **26.3** (built against **0.165.0+26.3**)

Install Fabric, then place `defy-1.0.0.jar` in your `mods/` folder.

## Using the menu

Type **`/defy`** in chat to open the menu. Set an opening/closing shortcut in **Settings > Menu toggle key**; it starts unbound. Escape closes the menu, and **Ctrl + K** focuses feature search.

Click a feature's **Bind** button to assign a key or chord. Escape cancels; Backspace/Delete clears a binding. Profiles keep separate feature options and bindings. Interface preferences are shared, and the profile carrying the **Default** tag loads at startup.

Use the profile dropdown at the top right to switch profiles while staying on the current page. **Manage profiles** opens the full profile editor. Click outside a text field to stop typing in it.
