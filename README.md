# defy

defy is a mod for Hypixel SkyBlock that focuses on quality-of-life improvements, customization, and features that go beyond what's normally allowed.

The mod is still in early development, with more features being added over time.

## Features

The current version mainly focuses on the menu and its customization.

- **Customizable menu** - A modern, native interface with four themes (Light, Silver, Ash, Dark), effects (None, Blur, Glass), and more.
- **Feature search** - Quickly find features without having to look through every category.
- **Keybinds** - Assign custom keys or key combinations to individual features.
- **Profiles** - Create, rename, and switch between profiles, each with its own feature settings and keybinds.

For now, some basic gameplay features are available, with more planned for future updates :)

## Installation

### Requirements

- Minecraft **26.3** (older and newer versions planned)
- Java **25**
- Fabric Loader **0.20.1+**
- Fabric API for Minecraft **26.3** (built against `0.165.0+26.3`)

Install Fabric and the required Fabric API, then place `defy-1.x.x+26.x.jar` in your `mods/` folder.

## Usage

Type `/defy` in chat to open the menu, or assign a keybind to open it under **Settings > Interface**.

You can customize the menu's appearance, manage profiles, and configure feature keybinds directly from the interface.

Profiles save their own feature settings and keybinds, while menu appearance settings are shared across profiles.
